# Subscription-tracker
Personal project that allows users to log, monitor and track their subscription services. 


# Version 1 feature scope
- Add / edit / delete a subscription
- Fields: name, cost, currency, billing cycle (monthly/yearly), next renewal date, category, notes
- View total monthly spend
- View list of all subscriptions, sorted by renewal date
- Basic login (single user account, no multi-tenant complexity yet)
